# Concepts

Experimental digital redesign concepts by Omar Akram.

This repository contains speculative web design and frontend development concepts created for portfolio and creative exploration. Each folder is a completely standalone Vite + React project with its own dependencies — `cd` into one, `npm install`, `npm run dev`.

## Nothing Personal

Unofficial digital redesign concept for Nothing Personal.

Fashion editorial / cinematic digital experience.

Folder: `nothing-personal/` — routes `/` and `/showcase`

## BE-INDIE

Unofficial digital redesign concept for BE-INDIE.

Experimental denim / print / fashion-lab experience.

Folder: `be-indie/` — routes `/`, `/showcase` and `/lab`

## Pop Spot

Unofficial digital redesign concept for Pop Spot.

Collectorverse / interactive collectibles / arcade-inspired ecommerce experience.

Folder: `popspot/` — routes `/` and `/showcase`

## In Your Shoe

Unofficial digital redesign concept for In Your Shoe (IYS).

IYS INTERNET 2006 — 2000s internet / simulated desktop ecommerce concept: today’s full public IYS catalogue running inside an original 2006-era computer (desktop OS + separate mobile shell).

Folder: `IYS/` — routes `/`, `/shop`, `/collections/*`, `/search`, `/product/*`, `/favorites`, `/stores` and `/showcase`
